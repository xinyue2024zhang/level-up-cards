# Level Up vocabulary cards

Self-contained daily vocabulary cards embedded in the Level Up Notion learning calendar. Each page contains its own word data, styles, interaction code, and British and American pronunciation recordings.

Tap to flip. Swipe left for the previous word and right for the next word.

Pronunciation uses a native HTML audio player with MP3 Blob URLs created from the embedded recordings. Playback starts directly from the user's tap and uses the media player's actual progress. No external audio request is needed.

The learning calendar now runs through 30 November 2026. November continues the original IELTS 3,575-word order (2,201–3,575), with 125 explicitly labelled review slots after the remaining new words. Existing September and October lessons and progress keys are preserved.

November examples and translations come from the existing study materials. Word order and phonetics follow [Qwerty Learner's IELTS list](https://github.com/RealKai42/qwerty-learner/blob/master/public/dicts/IELTS_3_T.json), with corrections for missing phonetics and heteronyms; November UK/US recordings use Youdao dictionary pronunciation. BBC audio and transcripts link to the official source. Where an older episode has no official worksheet, its PDF is clearly labelled as original Level Up practice. British Council B1 readings continue the established review cycle with explicit reading tasks. The standalone calendar exposes PDF links without requiring a Notion account.
